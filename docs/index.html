Features

Small app. No friction.

Everything happens in a single card under the menu bar icon. No windows to manage, no copy-paste between tabs, no extra accounts.

Clipboard-first

Every result is copied automatically. Paste it straight back into Slack, Mail or your editor.

Stays open

The card doesn't vanish when you click elsewhere, so you can grab text from another app and come back.

History

Your last 100 results, searchable. One click restores the input and output, ready to tweak.

Minimal edits

Fix mode changes as little as possible and keeps your tone, line breaks, names, links and emojis.

Native & light

SwiftUI, no Electron, no dependencies. A universal binary under 2 MB that never blocks the UI.

Accessible

VoiceOver labels and announcements, full keyboard access, and support for Increase Contrast and Reduce Motion.

Four modes

Fix it, polish it, or translate it.

Switch with a click or ⌘1–4. GrammarBar remembers your last mode, and Use as input lets you chain them — translate, then polish.

How it works

Your Claude Code, one hop away.

GrammarBar doesn't need an API key. It calls the Claude Code CLI you're already signed in to, headlessly, in the background.

Paste or type

Click the menu bar icon. The input is focused the moment the card opens.

Press ⌘↩

Your text is piped to claude -p over stdin with a mode-specific instruction.

Paste the result

The answer appears in the card and is already on your clipboard, and saved to history.

# what GrammarBar runs for each request claude -p "<mode instruction>" --model haiku --output-format text # your text → stdin

Safe input

Text goes through stdin, never a shell argument — quotes and newlines can't break anything.

Clean context

Runs in a temporary folder, so no project CLAUDE.md leaks into your request.

Finds claude anywhere

Checks the usual install paths, then falls back to your login shell — nvm and asdf setups just work.

Privacy

No servers. No tracking.

  • Your session, your data. Text goes to Anthropic through your own Claude Code login — exactly as if you typed it into claude.
  • Nothing in between. GrammarBar has no backend, analytics or telemetry.
  • Local history. Stored only on your Mac. Clear it in the app, or remove everything with brew uninstall --zap.
  • Open source. Every line is on GitHub under the MIT license.

Install

Up and running in a minute.

Install Claude Code and run claude once to sign in, then pick one:

Homebrew Recommended

Installs to /Applications and updates with brew upgrade.

brew install --cask sarifmiaa/tap/grammarbar

Build from source

Needs the Xcode Command Line Tools — no Xcode project.

git clone https://github.com/sarifmiaa/GrammarBar.git
cd GrammarBar && ./build.sh
mv GrammarBar.app /Applications/
macOS 13 Ventura or later Apple Silicon & Intel Claude Code, signed in
FAQ

Questions, answered.

Does it cost anything?

GrammarBar is free and open source. Requests use your existing Claude Code plan or usage, like any other claude command.

Which model does it use?

Claude Haiku by default, for speed. Change claudeModel in Config.swift to "sonnet" and rebuild for higher quality.

Can I add my own languages or modes?

Yes — each mode is a single case with its instruction in Mode.swift. Adding "Translate to Spanish" is a few lines.

It says “claude CLI not found”.

Install Claude Code and run claude once in Terminal to log in. GrammarBar checks the common install locations and your login shell's PATH.

macOS says the app can't be opened.

GrammarBar is ad-hoc signed rather than notarized. The Homebrew cask handles this for you; for a manual download, run xattr -dr com.apple.quarantine GrammarBar.app or allow it in System Settings → Privacy & Security.

How do I start it at login?

System Settings → General → Login Items & Extensions → Open at Login → +, then choose GrammarBar from /Applications.
